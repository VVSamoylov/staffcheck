Проект учета рабочего времени для съемочных групп. 
Веб интерфейс реализуется на ReactJS, серверная часть Java Spring.
Для обеспечения авторизации и аутентификации используется KeyCloack сервер.
Коротко в проекте назначение задач, выписка путевых листов для машин и учет пребывания в офисе путем выгрузки данных СКУД.
Установка сборка JS бандла и сборка Jar файла с включенным бандлом. В среде запуска должны быть прописаны переменные окружения для подключения к БД. 
БД по умолчанию PostgreSQL, но возможна любая, привязки к СУБД нет. 
установка с помощью скрипта DockerCompose/start сначала сборка и установка React интерфейса, потом мавен собирает jar файл затем собираются докер образ приложения.
Важно проверить и сделать настройки для своего домена, полоржить сертификаты. перед сборкой в файле gtrkstaff/src/AuthConfig правильно переименовать домены для сервера авторизации и ресурсного сервера
Указать в переменных окружения docker-compose файла пути к сертификатам, домены и пароли, так же положить импорт настроек keycloack если они есть в папку.
